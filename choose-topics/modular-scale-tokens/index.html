01 / The idea

A scale is a relationship

A modular scale starts with a base size and repeatedly multiplies it by a ratio. The ratio becomes one knob for the whole type hierarchy.

step sizebase × ratiostep
18px × 1.252= 28.13px

With pow(base, exponent), the first argument is the number being raised and the second argument is the power. In CSS, pow() lives inside calc(), so the browser computes each token from the base and ratio.

Changing the ratio from 1.25 to 1.333 shifts every computed step at once. That is the advantage over hand-picked font sizes: the hierarchy stays coherent while you explore its shape.

The token recipe

:root {
  --base: 1.125rem;
  --ratio: 1.25;
  --font-size-xl: calc(
    var(--base) * pow(var(--ratio), 2)
  );
}

04 / Go below zero

Negative exponents

A negative exponent divides by the ratio. This gives captions, labels, and fine print a deliberate place in the same system instead of an arbitrary smaller value.

Caption / xsSupporting text / smBody / md
--font-size-sm: calc(var(--base) * pow(var(--ratio), -1));

05 / Clean values

Use round() deliberately

Ratio math can produce fractional pixels. round() can snap a specific step to a clean interval when pixel alignment matters, without rounding every token and slowly distorting the scale.

True ratio35.15625px
Rounded to 1px35px
--font-size-xl: round(calc(var(--base) * pow(var(--ratio), 2)), 1px);

06 / Make it fluid

Let the base breathe

Put clamp() on the base and every computed step inherits that fluidity. This is concise and powerful; clamp steps individually only when each one needs a different range.

--base: clamp(1rem, 0.8rem + 1vw, 1.125rem);One fluid input propagates through the scale.

Takeaway

Scale, measure, rhythm.

Your size tokens set the type hierarchy. A comfortable ch width controls line length, while lh and rlh tie spacing to the same reading rhythm. Together, they make a system rather than a collection of unrelated numbers.
