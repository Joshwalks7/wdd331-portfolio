1. The two axes

Inline and block directions

The inline axis follows the line of text. The block axis stacks lines and sections.

2. Physical versus logical

The same active navigation link

Physical properties point to the screen. Logical properties point to the beginning of the text flow.

3. Property map

Common physical-to-logical replacements

margin-left→margin-inline-start
padding-top→padding-block-start
width→inline-size
height→block-size
text-align: left→text-align: start

4. Logical sizing

When to use inline-size and block-size

Use logical sizing for content and layout. In a horizontal writing mode, these behave like width and height. In a vertical writing mode, they rotate with the text flow.

.article {
  max-inline-size: 65ch;
  min-block-size: 20rem;
  margin-inline: auto;
}
inline-size: 100% block-size: 8rem

Keep physical width and height when a dimension is tied to a physical object or screen, such as a canvas, map, video, or fixed viewport overlay.

6. Test it yourself

Using DevTools

  1. Select the <html> element in the Elements panel.
  2. Change dir="ltr" to dir="rtl".
  3. Inspect the logical card and open the Computed tab.
  4. Notice how border-inline-start resolves to a physical side.

Changing the HTML dir attribute is a better real-world test than only adding direction: rtl in CSS because it also informs bidirectional text and assistive technology.
